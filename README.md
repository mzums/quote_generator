# 📜 **Quote Generator**

This project is a simple **Quote Generator** that displays motivational or famous quotes with an animated background. Every time you click the "Generate Quote" button, a new quote is displayed along with a fun confetti animation.

![alt text](image.png)

---

## 🎨 **Features**

- 💬 **Quote Generator**: Displays random quotes with smooth animations.
- 🎉 **Confetti Animation**: Confetti bursts when a new quote is generated.
- 📱 **Responsive Design**: The layout is fully responsive and adapts to different screen sizes.

---

## 🛠 **Installation**

### Prerequisites

Ensure you have a modern browser that supports HTML5, CSS3, and JavaScript.

### Steps to Run

1. **Clone the Repository**

    ```bash
    git clone https://github.com/mzums/quote_generator
    cd quote_generator
    ```

2. **Open `index.html` in Your Browser**

---

## 🚀 **How to Use**

1. **Generate a Quote**: Click the "Generate Quote" button to display a random quote.
2. **Confetti Animation**: Every time you generate a new quote, confetti will burst across the screen.
3. **Enjoy the Animated Background**: The background changes with mouse movement, creating a visually engaging experience.

---

## 🧑‍💻 **Tech Stack**

- **HTML5**: Markup for the structure of the page.
- **CSS3**: Styles, animations, and background effects.
- **JavaScript**: Logic for quote generation and interactive animations.
